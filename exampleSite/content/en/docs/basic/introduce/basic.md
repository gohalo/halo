## Key Features

1. **Directory as Structure**: Build multi-level documentation trees effortlessly using Hugo `_index.md` files and `menu.docs` configurations.
2. **Dark Mode**: Native support for light and dark theme switching, with automatic color synchronization for code blocks and diagrams.
3. **Full-Text Search**: Built-in offline search index accessible anytime via the `Ctrl + K` shortcut.
