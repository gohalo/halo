Welcome to the **Tabbed Docs** example. Using the top tab bar, you can organize different dimensions of documentation under a unified hierarchy:

- **User Guide**: Product manual supporting multi-version switching and multi-level categorized navigation
- **FAQ**: Dedicated tab for frequently asked questions
- **API Reference**: Interactive API documentation rendered from OpenAPI specifications
- **Support**: Right-aligned auxiliary help entry
