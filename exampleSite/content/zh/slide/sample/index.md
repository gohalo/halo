## 代码高亮与逐行演进

通过 `[行号|行号]` 语法翻页时分步聚焦代码：

```go [1-3|5-9|11-14]
package main

import "fmt"

type Service struct {
    Name string
    Port int
}

func main() {
    svc := Service{Name: "halo-docs", Port: 8080}
    fmt.Printf("Starting %s on :%d\n", svc.Name, svc.Port)
}
```

Note:
第一步展示包声明与导入；第二步聚焦结构体定义；第三步展示服务初始化与启动输出。

## 表格与架构对比

| 特性维度 | 传统演示软件 | Halo + Reveal.js |

## 常用快捷键速查

- `←` `→` `↑` `↓` / `Space`：二维方向翻页
- `ESC` / `O`：开启全局幻灯片鸟瞰图
- `S`：打开演讲者视图（含计时与备注）
- `Alt + 点击`：放大查看当前局部内容
- `Ctrl + Shift + F`：全文检索幻灯片内容
